# Asset attribution

The RiffRelay brand assets are maintained in the project-owned
[RiffRelay branding repository](https://github.com/RiffRelay/Branding). This
repository does not currently declare a license. The website uses the matching
SVG sources and PNG exports; no third-party art or logo was introduced.

| Asset | Source | Use |
|---|---|---|
| `public/branding/riffrelay-icon.svg` / `.png` | `Branding/assets/riffrelay-icon.svg` | Favicon, header, footer, and Discord preview |
| `public/branding/riffrelay-wordmark.svg` / `.png` | `Branding/assets/riffrelay-wordmark.svg` | Wordmark |
| `public/branding/riffrelay-banner.svg` / `.png` | `Branding/assets/riffrelay-banner.svg` | Banner |
| `public/branding/riffrelay-social-card.svg` / `.png` | `Branding/assets/riffrelay-social-card.svg` | Open Graph and Twitter/Discord link preview |
